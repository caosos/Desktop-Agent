What the words mean
Project = the repo and its work. Coordinator = the Claude session (or liaison) that steers it; idle means it is waiting for a message, not down. Dispatcher (Business OS) = the loop that launches its workers. Workers = jobs running right now, counted from live processes and the project's own feed.
IDLE = verified that nothing is running now. DOWN = a coordinator session that should be reachable is not, or a dispatcher is stopped with work queued. not verified = no telemetry, so no claim.
