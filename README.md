# Desktop-Agent

Desktop Agent - helper to navigate desktop screens and to supervise Workers
within projects and a second set of hands.

A persistent, local-first control plane that runs disposable, sandboxed AI
workers against a project's own durable truth, verifies their work, and
records receipts with provenance. First managed project: CAOSCARE.COM.

Start with `AGENTS.md`, then `START_HERE.md`.

The browser panel at http://127.0.0.1:8477/ is the owner interface, and the desktop widget is optional.
